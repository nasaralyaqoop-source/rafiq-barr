# رفيق البر

تطبيق ويب (Web App) لنظارة **Meta Ray-Ban Display**، يساعدك في البر والمقناص.

## الشاشات
| الشاشة | وش تسوي |
|---|---|
| **التوجّه** | سهم ومسافة إلى المخيم أو السيارة أو أي نقطة محفوظة أو القبلة |
| **رادار النقاط** | النقاط المحفوظة حولك (بير، صيد، طريق…) باتجاهها ومسافتها. تضغط أي نقطة فتتوجه لها |
| **أثر المشي** | يسجّل طريقك، وزر «ارجع على الأثر» يرجعك عليه نفسه |
| **الريح والغروب** | سرعة الريح واتجاهها بالنسبة لوجهك، ووقت الغروب أو الشروق. تحتاج نت |
| **الخريطة** | قمر صناعي (Esri) أو شوارع (OpenStreetMap)، مع نقاطك وأثرك |
| **احفظ نقطة هنا** | تختار النوع، وتكتب الاسم أو تقوله |
| **معايرة البوصلة** | لو السهم مو مضبوط: لف وجهك للشمال واضغط «هذا الشمال» |

## الخصوصية
- النقاط والأثر محفوظة على النظارة فقط (localStorage)، ولا تُرسل لأي خادم.
- **الريح:** تُرسل إحداثيات مقرّبة (نحو 100 م) إلى Open-Meteo.
- **الخريطة:** تُطلب صورها من Esri أو OpenStreetMap.

## التشغيل بدون نت
- **يشتغل بدون نت:** التطبيق نفسه، والنقاط، والأثر، والتوجّه، والرادار، لكن بعد أول فتح وأنت متصل.
- **يحتاج نت:**
  - **الريح:** تعرض آخر قراءة محفوظة.
  - **الخريطة:** تعرض فقط اللي شفته قبل وأنت متصل.

## التجربة على الكمبيوتر
افتح الرابط ومعه `?demo=1`. يمشّي التطبيق موقعًا وهميًا، وبياناته منفصلة عن بياناتك الحقيقية.

## التثبيت على النظارة
1. **فعّل وضع المطور:** في تطبيق Meta AI ← الإعدادات ← معلومات التطبيق ← اضغط رقم الإصدار 5 مرات.
2. **ارفع المجلد** على استضافة HTTPS، مثل GitHub Pages. ملف `.nojekyll` ضروري عشان يُنشر مجلد `.well-known`.
3. **ثبّته** بإحدى طريقتين:
   - **رمز QR:** طالعه بالنظارة. يحمل الرابط بهذي الصيغة:
     `fb-viewapp://web_app_deep_link?appName=رفيق%20البر&appUrl=<رابط-التطبيق>`
   - **من التطبيق:** في تطبيق Meta AI ← App connections ← Add a Web App، والصق الرابط.
